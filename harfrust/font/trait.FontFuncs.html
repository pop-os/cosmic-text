Expand description

Customizable font callback surface.

§Metrics scaling

All font metrics returned by these callbacks must be consistent with the scale factor configured via ShapeOptions::scale.

If no scale is set, values must be in unscaled font units (i.e. the same coordinate space as the font’s units_per_em). If a scale is set — for example font_size * 64 for FreeType-style 26.6 — then all returned values must already be in that scaled coordinate space.
